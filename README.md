# ECOS

Repository arsip untuk eksperimen pembuatan video sinematik ECOS.

## Status

Eksperimen video 3D berbasis Blender dan GitHub Actions dihentikan. Proses render sebelumnya terlalu lama dan belum menghasilkan video akhir yang berhasil diverifikasi.

Repository ini dipertahankan sebagai arsip teknis, bukan sebagai produk siap pakai atau workflow render yang terjamin berhasil.

## Isi repository

- `blender_scene.py` — skrip pembentukan adegan 3D.
- `trailer.py` — prototipe generator audio dan video.
- `.github/workflows/render.yml` — workflow eksperimen render GitHub Actions.
- `requirements.txt` — dependensi Python.
- `archive/README-render-attempt.md` — salinan README eksperimen sebelumnya.

## Catatan

Tidak ada klaim bahwa trailer 45 detik telah selesai dibuat. File video final belum tersedia atau terverifikasi. Workflow dan kode yang tersisa disimpan hanya sebagai referensi jika eksperimen ini ingin dilanjutkan di kemudian hari.
