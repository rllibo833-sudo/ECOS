# Nexus Roadmap

## Milestone 0 — Android foundation
- [x] Kotlin Android scaffold
- [x] Custom View UI foundation (no Compose / Material dependency)
- [x] Local catalog and file import
- [x] File-type classification
- [x] Article and graph foundations
- [x] CI debug APK workflow
- [ ] Verify build and install on a physical Vivo Y18

## Milestone 1 — Reliable library
- [ ] Import progress, cancellation, duplicate detection
- [ ] Search, sort, filters, collections, tags
- [ ] File details, safe delete, share/export
- [ ] Memory-safe thumbnails
- [ ] Markdown reader and source viewer
- [ ] ZIP inventory browser (safe, read-only first)
- [ ] PDF viewing and video playback

## Milestone 2 — Encyclopedia
- [ ] User-authored articles, infoboxes, table of contents
- [ ] Internal links and asset references
- [ ] Provenance and citations

## Milestone 3 — Canonical graph
- [ ] Typed directed edges with provenance
- [ ] Graph editing and confirmation
- [ ] Neighborhood expansion, pan, zoom, clustering

## Milestone 4 — Semantic discovery
- [ ] Local metadata/text extraction
- [ ] Explainable similarity candidates
- [ ] Accept/reject controls
- [ ] Keep suggestions separate from canonical graph

## Milestone 5 — Resilience and polish
- [ ] ECOS-inspired visual identity
- [ ] Accessibility and contrast checks
- [ ] Backup/restore and catalog integrity
- [ ] Low-memory performance tests

A milestone is complete only after behavior is implemented and tested. A successful compile alone is not proof that features work.
